# Projekti 4 – Oliot

Projekti 4 jatkaa Projekti 3:n peliä.

Peli kertoo pelaajasta, joka etsii kadonnutta avainta puistosta.

Projektissa käytetään kolmea luokkaa:

- pelaaja
- paikka
- esine

Pelaajalla on nimi, sijainti ja inventaario.

Paikalla voi olla esine.

Esineellä on nimi ja paino.

Peli on jaettu useaan Python-tiedostoon.
